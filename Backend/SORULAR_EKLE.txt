KONTROL SORGUSU (Soruların eklendiğini kontrol edin):
================================================================================

SELECT 
    s."Id",
    k."Isim" as "Kategori",
    s."SoruMetni",
    s."YuksekPuan",
    s."OrtaPuan",
    s."DusukPuan",
    s."Aktif"
FROM "Sorular" s
INNER JOIN "Kategoriler" k ON s."KategoriId" = k."Id"
ORDER BY s."KategoriId", s."Sira";

================================================================================
NASIL ÇALIŞTIRIRIM?
================================================================================

YÖNTEM 1: pgAdmin Kullanarak
-----------------------------
1. pgAdmin'i açın
2. Servers > PostgreSQL > Databases > postgres üzerine sağ tıklayın
3. "Query Tool" seçeneğini seçin (veya F5'e basın)
4. Yukarıdaki SQL komutlarını kopyalayıp yapıştırın
5. "Execute" butonuna basın (veya F5)

YÖNTEM 2: DBeaver Kullanarak
-----------------------------
1. DBeaver'ı açın
2. postgres veritabanına bağlanın
3. SQL Editor açın (SQL > SQL Editor > New SQL Script)
4. Yukarıdaki SQL komutlarını kopyalayıp yapıştırın
5. Execute SQL Statement butonuna basın (Ctrl+Enter)

YÖNTEM 3: DataGrip Kullanarak
-----------------------------
1. DataGrip'i açın
2. postgres veritabanına bağlanın
3. New > Query Console
4. Yukarıdaki SQL komutlarını kopyalayıp yapıştırın
5. Execute butonuna basın (Ctrl+Enter)
